# Contributing

Thanks for contributing to Telegram -> Discord Bridge.

## Development

1. Copy `.env.example` to `.env` and use test credentials.
2. Install dependencies with `python -m pip install -r requirements.txt`.
3. Run `python -m py_compile main.py` before submitting changes.
4. Keep credentials, Telegram sessions, databases, and webhook URLs out of commits.

## Pull Requests

Keep changes focused, describe the behavior you changed, and include the validation command you ran. Do not include real Telegram or Discord data in tests, screenshots, or logs.
